# Metal Slug – 2D Action Game

## About the Project
Metal Slug is a 2D side-scrolling action game developed in C++ using Object-Oriented Programming (OOP) concepts and the SFML library. It was created as a second-semester university project.

The game is inspired by the classic Metal Slug series and includes different playable characters, weapons, enemies, and vehicles.

## Features
- Four playable characters: Marco, Tarma, Eri, and Fio
- Four game levels
- Multiple weapons, including Pistol, Heavy Machine Gun, Rocket Launcher, Flame, and Laser
- Different enemy types with different attack behaviours
- Four vehicles: Metal Slug, Slug Flyer, Slug Mariner, and Amphibious Slug
- Player movement, jumping, shooting, and melee attacks
- Character switching
- Collectibles, supply crates, and POW interactions
- Health, lives, and damage systems
- Scrolling camera and level progression
- Background music and sound effects

## Technologies Used
- C++
- SFML (Simple and Fast Multimedia Library)
- Object-Oriented Programming (OOP)

## OOP Concepts
The project uses various OOP concepts, including:
- Classes and Objects
- Inheritance
- Encapsulation
- Polymorphism

## Project Structure
- `main.cpp` – Main game logic and entry point
- `Headers/` – Header files and associated C++ source files for different game components

## Controls
| Key | Action |
|---|---|
| Left / Right Arrow | Move |
| Space | Shoot |
| Up Arrow | Jump |
| Q / E | Switch weapons |
| F1 – F4 | Select character |
| Z | Switch character |
| C | Melee attack |
| V | Special power |
| X | Enter vehicle |
| Y | Exit vehicle |
| F | Interact with POW |
| K | Fire vehicle missile |
| A / D | Adjust aiming angle |

## Assets and Dependencies
The original game assets (images, sprites, fonts, and audio files) are not included in this repository.

The project requires SFML and the original asset files to run. Additional setup and include-path configuration may be required.
